# Music School Management System (MSMS)

A simple music school management system built with Python that allows you to manage students, teachers, and attendance records with persistent JSON storage.

## Features

### Student Management
- Add new students with enrolled courses
- View all students
- Filter students by course
- Update student information
- Delete students

### Teacher Management
- Add teachers with their specialities
- View all teachers
- Update teacher information
- Delete teachers

### Attendance Tracking
- Student check-in with timestamp
- View all attendance records

### Additional Features
- Print student ID cards (text file)
- View system statistics (total students, teachers, check-ins, most popular course)
- Persistent data storage using JSON

## Requirements

- Python 3.6 or higher
- No external libraries required (uses only standard library)
